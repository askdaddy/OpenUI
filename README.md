# OpenUI

面向 Forever、源码公开并拟免费供非商业使用的魔兽世界现代 UI 插件。当前只讨论方案并落实文档，尚未编写插件功能。

长期覆盖游戏内全部 UI，采用自有布局和现代扁平暗色风格；按综合玩家使用频度分批交付，模块可独立开关，关闭后允许恢复原生界面。
