# 聊天

[文档入口](../README.md) · [模块索引](../planning/模块索引.md) · [决策记录](../planning/决策记录.md)

状态：B0，默认启用。2026-11-19 用户确认当前聊天组件为阶段基线，暂停新增功能。基础实现由 [#74](https://github.com/askdaddy/OpenUI/issues/74) 和 [PR #75](https://github.com/askdaddy/OpenUI/pull/75) 交付，后续游戏内修正在本地工作区验证。设计见 Penpot「OpenUI → 聊天界面」。

## 界面与交互

- 消息和原生输入上下排列，共用一块半透明底板，中间用细线区分。消息左对齐，正文沿用频道色，时间戳可单独辨认。
- 默认只显示「综合」「战斗日志」。综合可显示多个频道；收到某频道的新消息后按需追加阅读页签，同频道复用，不切换当前视图。原生战斗日志仅显示内容区，隐藏其独立边框与工具。
- 角色显示为 `[等级 种族♀ 角色名]` 或 `[等级 种族♂ 角色名]`。缺少资料时省略对应字段。角色名与资料沿用职业色，道具以品质色展示为 `[道具名]`。保留原生角色和道具链接交互。
- 左侧方形功能栏依次为社交（O）、表情、宏、谈话、语言。入口调用客户端功能。
- 底部色线按「说、队伍聊天、团队、副本、公会、呼喊、悄悄话」排列；有权限的附加频道和已加入的公共频道可追加。基础频道暂不可发言时淡化并忽略点击。悬停名称贴近色线，悄悄话先填写收件人，再交给原生编辑器。
- 单击阅读页签切换视图，拖动页签移动整个组件，拖动右上三线手柄调整宽高。松手保存位置和尺寸。在「社交与交易 → 聊天」可选择 12、13、15、17 四档消息字号，首装默认 13，设置与布局随当前配置档保存。
- 停用恢复原生聊天外观与输入框。聊天角色链接沿用原生交互。实验性的 Ctrl + 左键观察已移除。

## 实现与核验

- 优先使用 Forever 聊天消息附带的角色 GUID。`GetPlayerInfoByGUID` 提供本地化种族（第 3 项）、性别编码（第 5 项）和可选等级（第 8 项）。必要时使用可见单位和已有名册数据；显示信息限于客户端返回的数据。
- 本地参考为 Ruyi 1.0.9 的 `examples/Ruyi/Modules/Chat/Chat.lua`，核阅日期为 2026-11-19。该实现说明可从原生 AddMessage 的事件参数读取发送者 GUID，再取可选等级；OpenUI 使用该接口线索，保留自己的格式化、显示和恢复逻辑。
- Lua 测试覆盖频道、姓名格式、物品、链接转发、布局持久化和原生恢复。客户端实际画面、频道权限、跨服个例仍以 Forever 游戏内观察为准。

频道缩写、方向键编辑、Shift 滚轮历史、Alt 点击邀请和自动加入频道继续后置。适用 [技术边界](../architecture/技术边界.md) 与 [Agent 工作约束](../../AGENTIC.md)。
