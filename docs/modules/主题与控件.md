## LSM 跨插件视觉共享计划（方向已确认）

用户已批准按“OpenUI 主题系统 + LSM 媒体桥接 + 第三方适配层”规划。LSM 作为媒体互通层，先规划媒体共享，再逐插件规划完整适配；库版本、分发方式和目标插件清单尚未决定，本轮不实现。

| 层次 | 职责 | 对其他插件的作用 |
| --- | --- | --- |
| OpenUI 主题与控件 | 配色、字号、间距、尺寸、状态与布局 | 管理自有界面；不因 LSM 注册而自动改变其他插件 |
| LSM 媒体桥接 | 注册及获取字体、状态条、背景、边框、声音 | 支持 LSM 的插件可以选择同一媒体；不保证自动切换或即时刷新 |
| 第三方适配（待决策） | 通过目标插件支持的配置/API或经研究的适配处理外观 | 完整统一颜色、布局、边距等需逐插件评估，未批准目标清单 |

已确认规划约束：只注册带 OpenUI 前缀的稳定媒体名，不修改其他插件配置，不默认调用 SetGlobal 强制覆盖。SetGlobal 只影响通过 Fetch 获取媒体的消费者，并非全局 UI 换肤，且影响面超过明确适配对象。是否提供用户授权的适配另议。

应处理延迟加载、媒体缺失、重复注册、禁用或卸载后的路径失效；导出只保存媒体标识而非素材本身，导入时提示缺失并按已确认规则回退。字体注册的语言 mask 按实际字形覆盖声明；手动中文 UI 在英文客户端的字形可用性需要另行检查，不能只依赖客户端语言筛选。

本地证据：ElvUI 16.01 的 `ElvUI/Game/Shared/Media/SharedMedia.lua` 使用 LSM 注册资源；其嵌入 LSM 源码依赖 LibStub 与 CallbackHandler，包含资源存在性检查。该快照不能替代在 Forever 70888 的验证，不在本轮引入库或复制媒体。

依据：[LSM 官方 API](https://www.wowace.com/projects/libsharedmedia-3-0/pages/api-documentation)。官方基础媒体类型为 font/statusbar/background/border/sound；自定义类型也需消费者主动约定，不能自动形成主题标准。

已确认双向媒体共享：向外注册 OpenUI 素材，同时允许选择外部插件注册的媒体。首批研究对象为 Forever Meter、Questie、DBM-Core；仅确定研究对象，不承诺完整适配。待用户决定：LSM 版本与嵌入或可选依赖方式；缺失媒体回退行为。引入方向已批准，具体库分发与打包结构尚未冻结。

## 分步计划

| 阶段 | 文档与方案工作 | 进入实现前的确认项 | 后续验收目标 |
| --- | --- | --- | --- |
| T1：主题契约 | 整理语义 token、字体角色与状态条/背景/边框资源职责，统一模块覆盖规则 | 默认资源与许可、token 值、覆盖和重置规则 | 各已交付自有界面使用同一套视觉规则，模块覆盖和重置符合规格 |
| T2：媒体互通 | 规划稳定 OpenUI 媒体名称、资源清单、LSM 注册/获取边界、依赖加载和缺失处理 | 库版本与分发方式、是否读取外部媒体、标识与回退策略 | 支持 LSM 的目标插件能发现并使用批准素材；延迟加载、重复注册及中英文字形检查通过 |
| T3：配置接入 | 定义选择器、预览、导入导出标识与缺失提示，不将素材嵌入配置串 | 选项范围、缺失媒体导入行为、即时/重载刷新方式 | 配置导入两种模式均保留媒体选择语义，缺失资源按确认策略处理，无静默替换 |
| T4：第三方适配试点 | 按用户指定的插件研究公开 API、配置、刷新和恢复能力，比较媒体共享与完整适配差距 | 首批插件及版本、覆盖项、用户启用与恢复流程、交付时点 | 选定插件在确认范围内应用外观；停用适配按约定恢复，不改变未授权的业务设置 |
| T5：扩展维护 | 记录适配矩阵、版本范围、限制与回归用例 | 后续目标和维护承诺 | 每个适配有明确兼容范围，不宣称所有插件自动支持 |

T1 为 B0 主题基础的细化；T2–T3 拟作为 B0 媒体能力接入，具体范围待冻结。T4–T5 的批次暂不指定，需与“核心替换先于增强”规则一起由用户确认，不能借本计划提前第三方适配。

依赖顺序：主题契约 → 媒体互通 → 配置接入 → 适配试点 → 扩展。每步先确认方案再实施，不以该顺序授权本会话写代码。只有后续已落地的代码变化记录在根 CHANGES 当前待发布版本，设计阶段不记入。
