## 范围与交付

- 批次：B0。
- 首装状态：默认启用。
- `/openui` 打开 700 × 520 的单一主控窗口。采用直角控件，固定页眉含搜索、布局编辑和关闭，固定页脚左侧显示「修改即时生效」，右侧为「关于 OpenUI」。需要延后或重载的选项应就地提示。
- 分类页签位于顶部。左侧纵向模块菜单负责选择模块，右侧内嵌该模块配置。右侧正文溢出时可用滚轮和可见滚动条浏览；滚动时页签、左侧模块菜单和页脚固定。

| 分类 | 模块顺序 |
| --- | --- |
| 插件设置 | 主题、本地化、配置档、布局网格、诊断 |
| 战斗 HUD | 动作条、单位框体、施法条、光环、名牌 |
| 地图与任务 | 小地图、世界地图、任务 |
| 游戏窗口 | 背包与银行、角色与装备、法术书与天赋、专业与成长、提示框、系统界面、特殊场景 |
| 社交与交易 | 聊天、队伍与团队、社交与组队、NPC 交互、交易与邮件、拍卖行 |

- 主题、本地化、配置档和布局网格默认可用。左侧状态点与右侧启停开关仅用于支持启停的模块，插件设置中仅诊断保留这两项。布局网格仍可单独调整显示、尺寸和吸附。`Settings` 的管理功能由主控窗口提供。
- 七套主题应用到整个窗口，包括底板、页眉页脚、侧栏、卡片、边框和滚动条。切换模块后继续使用所选主题，选择器中的各配色色样保留原色。
- 「关于 OpenUI」打开独立视图，只有「关于 OpenUI」和「返回」两个页签，隐藏左侧模块菜单。右侧正文可滚动，包含项目简介、作者、联系邮箱、项目主页、Issue 反馈入口，以及媒体初始化和检测到 LibSharedMedia 后自动桥接的说明。点击「返回」恢复打开关于页前的模块视图。媒体桥接无需单独的设置入口。
- 「配置档」内嵌当前角色和账号共享槽的管理界面，行为遵循 [配置档规格](配置档.md)。

## 待确认与核实

保留按本地化模块名或分类名搜索及无结果提示；具体跨页签的焦点、清空后的恢复和键盘行为在实现计划中核验。Penpot 的静态画板跳转用于演示设计，实际交互以冻结计划与 Forever 验收为准。

## 共通约束与验收方向

遵循 [技术边界](../architecture/技术边界.md) 和 [Agent 工作约束](../../AGENTIC.md)。已交付功能模块可关闭并恢复原生界面；具体即时、脱战或重载流程待确认。自有 UI 应纳入主题、本地化、配置与诊断；依赖关系及验收用例需在实现前确认，不将代码文件存在当作功能验收。
