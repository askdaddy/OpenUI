# 配置档规格

[返回 README](../../README.md) · [规划](../planning/项目规划.md) · [待决策](../planning/决策记录.md)

状态：部分行为已确认，其余待决策；不作为实现批准。

## 已确认行为

- 支持角色独立配置。
- 提供账号级 5 个共享槽。
- 角色使用共享槽时持续关联该槽，不采用一次性复制语义。
- 修改共享槽影响所有关联角色。
- 删除共享槽时，为所有关联角色保留独立副本。
- 支持导入导出；前缀为 `OPENUI_SETTINGS`。
- 从角色独立配置切换到共享槽时，保留原独立配置。
- 解除共享槽关联时，由用户选择复制共享槽当前配置，或恢复原独立配置。
- 导入支持两种方式，由用户在导入时选择：选中模块整体替换；或仅覆盖导出串含有的字段、保留模块内其余字段。未选模块保持不变。
- 导入流程：先校验并预览，选择目标配置与模块，再确认应用；目标为共享槽时列出受影响角色；校验失败不修改配置。
- 模块开关、外观、模块选项和窗口布局可以共享及导出；错误记录、资源采集记录等运行数据不进入配置串。角色与职业专属选项另行讨论。
- 不支持的格式版本拒绝导入；未知模块可由用户明确选择跳过，再导入其余模块，不静默丢弃。

## 删除共享槽的验收意向

假设角色甲和乙均关联共享槽 1：删除槽 1 后，甲和乙各自保留删除前的共享配置，之后独立修改；不因删除丢失正在使用的设置。

该行为需要覆盖未登录角色；具体存储结构、失效处理与验证方法尚未选定。

## 待确认行为

- 没有历史独立配置时，解除关联的可选项及回退行为。
- 嵌套字段、数组、显式删除值的合并规则；格式版本的具体支持范围与迁移规则。
- 预览详情、确认时目标已变化的处理，以及应用阶段失败恢复。
- 共享修改提示方式；已在线角色何时刷新，以及需重载或战斗后应用的处理。
- 角色与职业专属选项的共享范围、不适用选项的显示与应用行为。
- 槽位命名、空槽、重置、覆盖，以及配置格式迁移。
- 编码、校验算法、格式版本、长度限制与输入校验。
