状态：方案与文档阶段，不授权功能开发。本文件只维护跨模块产品方向，具体功能以各模块唯一规范为准。

## 已确认方向

- 正式名称 OpenUI；Ruyi 仅作功能参考，不作为配置兼容目标。
- 长期仅面向 Forever，本机版本 1.60.1.70888；匹配该构建的 API 与安全限制仍需验证，见 [客户端资料](../references/Forever客户端.md)。
- 长期覆盖游戏内全部 UI，采用自有布局与现代扁平视觉，允许客户端基础控件、经筛选模板及必要安全机制；不强制依赖现成 UI 插件，通用库另议，见 [技术边界](../architecture/技术边界.md)。
- 模块可以独立开关，关闭后允许恢复原生 UI；具体脱战或重载条件逐模块确认。
- 面向升级、日常、副本均衡的综合玩家，按使用频度排序；分批发布，每批已完成模块可独立使用。同频度下依赖先行须标明原因并请用户确认。
- B0–B5 排序已确认为细化基线，具体窗口继续讨论。核心界面替换先于工具增强，工具启动节点暂缓。
- 现代扁平暗色预设、深度自定义、英文与简体中文、统一设置、配置共享与诊断属于共通产品能力；具体行为归入对应模块。
- 设置页和工具不固定数量；天赋窗口纳入替换，额外天赋模拟器不做；禁用弹窗仅保留研究。

## 文档与决策规则

- 除 README.md、AGENTIC.md、CHANGES.md 外，所有项目文档放 docs/；后两者是用户明确指定的根目录例外。
- docs/modules/ 每模块一个规范，包含已确认范围、待决策和相关研究；模块分组不提前冻结代码或插件包架构。
- 未决事项必须由用户拍板，不能用默认建议、沉默或等待超时代替答复。
- examples/ 为只读本地参考，不提交或打包。参考实现不代表 OpenUI 已实现，也不代表本机已验证。
- 仅已落地的代码变化按版本记录在 [CHANGES](../../CHANGES.md)，当前规划版本为 `2026.11.0-dev.1（未发布）`，规则见 [版本规则](版本规则.md)。
