## 一、名称、权利人与适用范围

1. 暂用名称为“OpenUI 非商业共享许可证”。**待决策 L01：正式名称、许可版本及生效日期。** 项目发布版本与许可证文本版本分别管理，不因项目版本更新自行改变许可条款。
2. 项目作者版权署名为 `askdaddy`。商业授权申请联系邮箱为 `askdaddy@gmail.com`。第三方贡献者保留对各自贡献的权利，该署名不表示 askdaddy 拥有所有贡献的版权。
3. 本许可拟适用于由相关权利人明确指定适用本许可的 OpenUI 原创代码与素材。素材包括项目有权许可的纹理、图片、声音及其他资源；不因文件位于仓库内就推定其适用本许可。
4. 第三方库、字体、素材及其他内容按各自许可证或授权使用，不适用本许可新增的非商业限制。引用、嵌入或经 LSM 注册不改变其原有许可。
5. **待决策 L02：逐项确认原创文件、文档、数据、字体及贡献的适用清单和声明方式；不将来源不明文件纳入许可。**

## 二、免费非商业使用与对接

1. 在遵守本许可条件的前提下，允许免费进行非商业使用、复制、修改及再分发 OpenUI 适用部分。
2. 允许其他免费非商业插件使用或对接 OpenUI。若复制、修改或再分发 OpenUI 的代码或素材，应同时遵守第四节；仅调用接口的独立插件，不因此要求公开其全部独立代码。
3. 上述许可不包含第三节明确禁止的活动；第五节例外及第六节另行书面授权分别适用。
4. **待决策 L03：收费独立插件仅调用 OpenUI 接口，或通过 LSM 获取、使用 OpenUI 原创媒体的行为如何处理。该事项明确暂缓，本草案既不认定其全部允许，也不认定其全部必须取得商业授权。正式文本须解决其与一般非商业限制的关系。**

## 三、未经书面授权禁止的活动

未经第六节所述有权主体的书面授权，不得：

1. 销售适用本许可的 OpenUI 代码、素材或其修改版。
2. 以付费、订阅或必须捐赠为条件解锁其功能或取得访问资格。
3. 将适用部分用于收费整合包或收费整合活动。
4. 利用适用的 OpenUI 代码或素材提供收费服务。
5. 领取因分发 OpenUI 或适用本许可的修改版而产生的平台作者奖励；第五节的自愿捐赠例外不构成领取此类奖励的许可。

本节须与第五节明确允许的场景一并阅读，不能解释为禁止所有与收入有任何关联的个人正常使用。**待决策 L04：其他尚未列明的商业利用形式及相关定义，不以本草案自行补足。**

## 四、再分发与修改源文件

1. 再分发 OpenUI 适用部分或其修改版时，应保留对应版权署名、提供适用许可，并对修改作出说明。
2. 再分发修改版时，至少向接收者提供其中 OpenUI 相关部分的完整可编辑源码，以及修改素材的源文件；不要求向所有公众发布。
3. 不得仅以不可编辑产物代替前款要求的源文件。该义务针对 OpenUI 相关部分，不因此要求公开仅通过接口对接的独立插件的全部代码。
4. 再分发的 OpenUI 部分及其修改继续沿用本许可的非商业限制和修改公开要求；第三方内容继续保留其原许可，不将两者混为一体。
5. **待决策 L05：源文件与产物是否同时提供、提供渠道、后续可获得期限及合理传输成本的处理。不得先行认定只提供一个链接或只接受事后申请即满足义务。**
6. **待决策 L06：可编辑源码及素材源文件的具体边界，例如生成素材所需的工程文件、脚本和构建资料；同时明确不要求提供无权披露的第三方内容。**

## 五、明确允许的收入相关场景

1. 主播可以在含广告或打赏的直播中正常使用 OpenUI；这不授予销售、收费解锁、收费整合或收费服务的权利。
2. 免费插件作者可以接受无门槛的自愿捐赠。用户无需捐赠即可获取全部功能和访问资格；不得以捐赠之名收取实质性功能费用。
3. 允许在展示广告的分发平台免费发布 OpenUI 或合规修改版，但不得领取该分发产生的平台作者奖励。
4. 本节例外不豁免第四节的再分发要求，也不改变第三方内容的原许可。

## 六、个别书面商业授权

1. 商业用途可另行申请书面授权。本许可本身不自动授予商业权利。
2. 申请联系邮箱为 `askdaddy@gmail.com`；发送申请、收到邮件或未收到回复不等于取得授权。
3. 不默认将贡献者的商业授权权利转让或授予 askdaddy。个别商业授权如涉及第三方贡献，须征得相关贡献者同意。
4. askdaddy 不能仅凭项目维护者身份许可他人拥有的代码、素材或贡献；第三方内容的授权仍须符合相关权利人的许可。
5. **待决策 L07：书面授权的有效形式、明确范围、期限及权利核验流程。贡献提交流程与权利归属记录另行设计，不以普通贡献合并视为同意商业再许可。**
